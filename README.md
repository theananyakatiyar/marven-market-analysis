# Marven Market Analysis
A multi-page interactive business intelligence dashboard built in Power BI using the Maven Market retail dataset (1997–1998). The dashboard covers Sales, Orders, Returns, Customer, and Store performance analysis across the USA, Mexico, and Canada.

## Preview
| Page | Focus |
|---|---|
| Sales Analysis | Revenue, profit, trends by month and region |
| Orders Analysis | Order volumes, inventory age, brand correlations |
| Return Analysis | Return rates, revenue lost, problem products |
| Customer Analysis | Demographics, income, occupation segments |
| Store Analysis | Store-level performance and regional breakdown |

##  Tools Used
- **Power BI Desktop** - Dashboard development
- **Power Query** - Data transformation and appending transaction tables
- **DAX** - Custom measures and KPIs
- **CSV Files** - Raw data source (Maven Market)
